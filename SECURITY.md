# Security policy

Report a vulnerability through GitHub's private advisory form for this repository:
[Report a vulnerability](https://github.com/ClawdBuilder/jig-bedrock/security/advisories/new).

Do not open a public issue or post a real credential. Include the tag, the Pi, Node and AWS CLI versions, the provider
configuration (without secrets), the request or command, and what happened instead.

Only the latest release on the Releases page is supported. A branch or an older tag changes or is out of support; move
to the latest release first.
